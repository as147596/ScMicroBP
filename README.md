# Single-Cell Microbiome Interactions in Blood Pressure Regulation(ScMicroBP)

## Introduction
This repository contains a complete set of scripts for Single-Cell Microbiome Interactions in Blood Pressure Regulation.

## Main scripts include:
** species_dif.R: **
This script is used to perform differential species analysis across multiple hypertension cohorts.

** net.R: **
This script is used for the construction and analysis of gut microbiota co-occurrence networks.

** SingleCell_Preprocessing: **
This file performs single-cell data preprocessing, including dimensionality reduction, clustering, and cell annotation.

** scBPS.sh: **
This script is used to calculate single-cell bacterial polygenic scores (scBPS) and assess their statistical significance.

** scBPS Analysis.R: **
This file contains the analysis of scBPS results, including filtering significant microbe–single-cell interactions and their visualization, as well as functional relationship analysis between specific microbes' scBPS and cell subtypes.

** Tcell.R: **
This file contains the analysis of interactions between microbes and T cell subtypes.

** util.R: **
This file contains the functions used for analysis or visualization in this study.
